# Ledger de Dívida Técnica

O ReciMe ainda não carrega dívida técnica registrada. Quando uma limitação estrutural sobreviver a uma história, crie um arquivo em `items/` com estado `Carried`, `Paying`, `Paid` ou `Dropped`.

Cada item deve explicar a origem, motivo de carregamento, impacto, gatilho de revisão e condição de encerramento. Limitações pequenas e locais podem permanecer na revisão da história.
