## Convenções

Use `CV<N>` para Value, `DS<N>` para Delivery Story, `US<N>` para User Story e `TS<N>` para Technical Story. Estados válidos: `Planned`, `Active`, `Blocked`, `Validated`, `Done`, `Deferred` e `Dropped`.

Cada item deve descrever intenção, escopo, condição de aceitação, rota de validação e exclusões. Não use este índice como uma tabela detalhada de tarefas.
